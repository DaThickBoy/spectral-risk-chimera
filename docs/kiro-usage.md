# How we used Kiro

The project owner used Kiro to review and revise the requirements, create the design and task plan, and implement and test bounded slices of Spectral Risk Chimera. The owner approved financial rules, interfaces, and scope before implementation and reviewed the results. When the owner challenged a spec edit that had failed to persist, Kiro reproduced the diagnostic, corrected the property headings and validation references, and checked the result. [Requirements](../.kiro/specs/requirements.md) · [Design](../.kiro/specs/design.md) · [Task plan](../.kiro/specs/tasks.md) · [Financial steering](../.kiro/steering/financial-rules.md)

## Three examples

1. **Type 7 quantile and VaR.** The owner asked for the specified Decimal.js quantile as a standalone task, with focused tests. Kiro implemented it and added known-answer cases and a property test against an independent BigInt-fraction reference. In a later task, Kiro integrated it into the historical-simulation VaR engine. [Quantile](../src/risk/quantile.ts) · [Property test](../test/property/quantile.property.test.ts)
2. **Signed-zero histogram regression.** The owner supplied the CI counterexample and scoped the fix to bucket indexing. Kiro traced the failure to a negative-zero index, normalized it to positive zero, and added a unit regression and a property test that replays the original failing seed. [Fix and tests](https://github.com/DaThickBoy/spectral-risk-chimera/commit/1d0c159)
3. **ECB provenance and deterministic replay.** The owner approved storing the published ECB quote alongside the derived inverse and exporting both portfolio views with recorded inputs and a fixed clock. Kiro implemented the SQLite provenance changes, replay exporter, and browser checks. The owner confirmed the published value would be stored as exact canonical decimal text. [Provenance test](../test/integration/fxProvenancePersistence.test.ts) · [Replay exporter](../src/main/replayExport.ts)

The public dashboard is a recorded DEMO replay served as static files. The exporter uses a fixed reference clock of `2026-11-06T16:00:00.000Z`, synthetic market data, and one hash-checked ECB response. It preserves the recorded response and distinguishes the published quote from the derived conversion rate. Synthetic sentiment is display-only and does not influence VaR. Adjusted VaR remains unavailable under OD-1, and production startup remains blocked under OD-19. [Public replay manifest](https://dathickboy.github.io/spectral-risk-chimera/replay/manifest.json) · [Scope and limitations](../README.md#limitations-and-deferred-work-honest-list)
